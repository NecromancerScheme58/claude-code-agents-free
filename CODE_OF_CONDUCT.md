## 🤖 Your Autonomous Coding Swarm

**Claude Code Agents Free** is a groundbreaking, open-source collection of autonomous AI agents designed to live directly inside your terminal and IDE. 

We all know Claude 3.5 Sonnet is an absolute beast at writing code. But what if it could write code, run the tests, read the error logs, and fix its own mistakes without you typing a single prompt? That is exactly what these agents do. By utilizing the Anthropic API, this toolkit provides a suite of specialized agents: a Refactorer, a Unit Tester, a Bug Hunter, and a Documentation Writer.

You don't just get a chat interface; you get a fully autonomous development team. You give the agent a high-level goal, and it breaks it down, reads your codebase, creates the necessary files, runs the terminal commands, and iterates until the job is done. 

> 💡 **Why use these agents?** Because your time is too valuable to spend writing boilerplate or debugging silly syntax errors. Let the agents do the grunt work while you focus on the architecture.

## 🚀 Quick Start

> **Three steps. Under two minutes. No installation required.**

### 1️⃣ Clone the repository

```bash
git clone https://github.com/yourname/claude-code-agents.git
cd claude-code-agents
```

### 2️⃣ Install and configure

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="your-api-key-here"
```

### 3️⃣ Run your first agent

```bash
python agent.py --role debugger --file app.py
```

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🧠 **LLM Engine** | Handles reasoning and code generation | `Anthropic API` |
| 🛠️ **Tooling** | Allows AI to run terminal commands and edit files | `LangChain` |
| 💾 **Memory** | Remembers context across long coding sessions | `ChromaDB` |
| 🖥️ **CLI** | Beautiful terminal interface | `Rich` / `Typer` |

</div>

The agents use a ReAct (Reasoning and Acting) loop. They think about the problem, choose a tool (like `read_file` or `run_command`), observe the result, and continue until the task is complete.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is this officially made by Anthropic?</b></summary>

No. This is an **independent, open-source framework** built on top of the Anthropic API. It is not endorsed by or affiliated with Anthropic.
</details>

<details>
<summary><b>Do I need to pay for this?</b></summary>

The code is 100% free. However, you will need an Anthropic API key to use the agents. You pay only for the tokens you use (which is very cheap compared to hiring a dev).
</details>

<details>
<summary><b>Can it access my entire computer?</b></summary>
Yes, the agents have terminal access to the folder they are run in. It is highly recommended to run them inside a Docker container or a virtual environment for safety.
</details>

<details>
<summary><b>Can I use local models like Llama 3?</b></summary>

Yes, the framework is model-agnostic. You can plug in Ollama or vLLM to run the agents completely locally and for free, though Claude 3.5 Sonnet currently provides the best coding performance.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include your OS, Python version, and the terminal output of the agent crash.
</details>
